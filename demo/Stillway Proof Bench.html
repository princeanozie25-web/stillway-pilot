Stillway Proof Bench

A trained planner for dispatch jobs of any length. Build a job, pause it, correct the order, and see the plan change. Then run the check that covers every job that could ever be built.

The job

closed   open (gate A, gate B) L / R route taken   step changed by the correction code = what the reader carries back from the legs after this one

The check

The planner reads a job from the last leg back to the current one and carries a single code. The check lists every code that can ever arise, beside what the exact planner would hold at the same place. For each of them it tries every kind of leg and every gate state. If no entry is wrong, the planner is right on jobs of every length.
